CPD Automação Industrial - Site novo v6

IMPORTANTE:
Esta versão foi ajustada para o GitHub com nomes de pastas sem acentos e sem espaços.
Isso evita erro de imagem quebrada no GitHub Pages.

Como subir:
1. Extraia este ZIP.
2. Abra a pasta extraída.
3. Selecione TUDO que está dentro dela: index.html, style.css, script.js, CNAME, robots.txt, sitemap.xml e todas as pastas.
4. Arraste tudo para o GitHub em Add file > Upload files.
5. Faça Commit changes.

Não envie o ZIP fechado.
Não renomeie as pastas.
O arquivo CNAME deve ficar na raiz para manter cpdautomacao.com.br.
